Colourpicker Portrait

Assignment

Creative Computation, sept 2026

Using a Colourpicker tool, recreate a pattern representing a portrait of yourself.

Medium

p5.js, javascript

Tags

code programming javascript drawing photography p5.js CreativeComputation

I started with the idea of simplifying my portrait into large areas of colour, taking inspiration from the structure of a bar graph. I experimented with using vertical bars to represent different parts of the image, but found that uniform bars made the result feel too rigid. By allowing some of the bars to extend downward at random, I discovered a paint-dripping effect that made the portrait more dynamic while still keeping the original colours recognizable. I then adjusted the size and randomness of the bars until the effect felt balanced, resulting in a portrait that combines the structure of the original image with a more abstract, generated style. 


async function setup() {
    createCanvas(200, 250);
    img = await loadImage('me.jpg');
    img.resize(width, height);
    translate(width, height);
    scale(-1, -1);

    noFill()
    noStroke()
    // stroke('white')
    rectMode(CORNERS)
    let tile = 5
    randomSeed(1504)
    
    for  (let x = 0; x <= width; x += tile){
        let counter = 0;
        for  (let y = 0; y <= height; y += tile){
        if( random() <= 0.65 && y < height-tile){
            counter += 1;
        }
        else if(y >= height-tile){
            fill('white')
            rect(x, y, x-tile, y-counter*tile, 100, 100, 0, 0);
        }
        else{
            let c = img.get(width - x, height - y + tile ); 
            fill(c);
            rect(x, y, x-tile, max(y-counter*tile, 0), 100, 100, 0, 0);
            counter = 1.5;}
        }
    }
}
