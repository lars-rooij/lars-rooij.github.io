KinderEgg 3D Model

Assignment

Creative Computation, oct 2026

In OpenSCAD, make a little 3D model that can fit within a Kinder Surprise Egg.

Medium

openSCAD

Tags

code programming javascript drawing 3Dmodeling 3D CreativeComputation

Kinder surprise eggs always remind me of small model kits, that you get to put together yourself. Therefore I wanted to make something that should, idealistically, fit multiple parts together. Given that the lecture was also about plotting, which can make complex shapes based on simple movements, I figured it's just right (to at least make an attempt) to make this. Each of these parts lay flat on a printbed, and the result (both apart and put together) fits within an egg! 


area_length= 24;     // mm, final theorethical vertical movement.
area_width = 18;   // mm, final theorethical horizontal movement.
height = 10; // mm, max height of the arms.

module base(){
    difference() {
      color("blue") cube([area_length, area_width+2*4, 4]);  
      translate([1, 1 , 2]) cube([2.6, 2.6, 4]);
      translate([1, area_width+2*4-3.6 , 2]) cube([2.6, 2.6, 4]);
      }
}

module arm_left(){
  translate([1.3, 1.3 , 2]){
    color("yellow")  cube([2, 2, 2]) ;
    translate([-1, -1,2]) color("yellow") cube([3,3,height]);
    translate([-1, 2,height-1]) color("yellow") cube([3,area_width +1,2]);
    translate([-1, area_width +3 ,height-0.6]) color("yellow") cube([3,2 ,1]);
  }
}

module arm_right(){
  translate([1.3, area_width+2*4-3.6 + 0.3, 2]){
    color("yellow")  cube([2, 2, 2]); 
    difference(){
      translate([-1, 0 ,2]) color("yellow") cube([3,3,height]);
      translate([-1, 0 ,height-1]) color("yellow") cube([5,2,1.6]);
      }
  }

}

module head(){
  rotate([180,180,0]){
    translate([-area_length+ 3,-10,0]){
      translate([-1, 0 ,4]) color("red") cube([1,3,height]);
      difference(){
        translate([-1, 0 ,height-0.5]) color("red") cube([area_length,3,5 ]);
        translate([-1, 0 ,height+0.6]) color("red") cube([area_length-1,5,2.6 ]);
      }
    }
  }
}


base();
head();
arm_left();
arm_right();
